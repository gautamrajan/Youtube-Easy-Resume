Storage schema version: 1

    Each current video is stored under "video:<youtube-video-id>": {
        videolink,
        time,
        duration,
        title,
        channel,
        complete:boolean,
        doNotResume:boolean,
        updatedAt: Unix timestamp in milliseconds,
    }

    videoStorageVersion: 1

    Migrated records use "legacyVideo:<youtube-video-id>" until the
    next playback write. Canonical "video:" records always take precedence.

    settings:{
        pauseResume: boolean,
        minWatchTime: value in seconds,
        minVideoLength: value in seconds,
        markPlayedTime: value in seconds,
        deleteAfter: days
    }

See ../STORAGE.md for migration and expiry semantics.
